# litium-developer

A comprehensive development skill for Litium partner developers — covers React Accelerator (Next.js), MVC Accelerator (.NET), back office UI extensions, data modelling, APIs, local setup, and troubleshooting.

## Install

```bash
npx skills add https://github.com/LitiumAB/agent-skills --skill litium-developer
```

## What it does

- Sets up local Litium environments (Empty Project, MVC Accelerator, React Accelerator)
- Develops React storefront components, pages, GraphQL queries/mutations, and template routing
- Develops MVC controllers, Razor views, view models, and client builds
- Builds back office UI extensions with Custom Elements (React, Vue, Angular, vanilla JS)
- Creates field types, field templates, multi-fields, and other data models
- Works with Admin Web API, Storefront GraphQL API, Connect ERP/Payment/Shipment APIs
- Searches forum.litium.com for community solutions
- Enforces partner guidance rules (public vs. internal APIs, protected projects)
